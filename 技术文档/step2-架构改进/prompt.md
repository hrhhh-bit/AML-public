# 架构演进任务书：跨链 AML 行为拓扑（Stage-1）宏观尺度与流向权重先验增强

## 1. 架构目标与铁律原则

本框架为 Stage-1 抽象行为拓扑生成系统，为下游 Stage-2 条件图扩散模型提供合规 DAG。本次增强旨在补齐关键反洗钱行为学特征，同时必须绝对恪守以下底线：

1. **零微观数值噪声（Zero Micro-Numerical Noise）**：严禁引入真实/伪造的钱包地址、具体 Token 单位、Gas 费、时间戳或微观绝对金额；
2. **两阶段职责解耦**：微观交易数据的连续分布扩散归属于 Stage-2，Stage-1 仅负责高层认知规划、拓扑结构及相对流向先验；
3. **物理守恒与硬规则拦截**：所有分流行为必须满足拓扑流向守恒律，由校验器拦截并触发 Agent 自我反思纠错，不依赖 LLM 的计算自觉。

---

## 2. 核心概念与数据契约演进纲要

### A. 场景规格层（Scenario Specification）

- **引入宏观资金规模等级（Scale Tier）**：
  - 增加表示资金体量的离散枚举（如 `Retail`、`Medium`、`Whale`、`State_Sponsored`），用以从宏观意图上指引拓扑深度与混淆复杂度；
  - 增加可选的宏观基准标量金额（如目标洗钱总估值 USD），该值**仅作为透传给 Stage-2 的静态元数据**，在 Stage-1 的多步决策循环中**严禁参与任何余额计算或扣减操作**。

### B. 拓扑图数据契约（Graph Entity Contracts）

- **边（Edge）增加拓扑流向权重（Flow Share）**：
  - 在边的抽象数据契约中新增归一化流向比例字段（取值区间 `(0.0, 1.0]`，类型为浮点数）；
  - **向后兼容性**：默认值设为 `1.0`，保证单向操作（Transfer、Swap、Bridge）与既有历史测试不受影响；
  - **业务语义**：用于从几何与行为学上区分同构子图（例如：区分“大额沉淀+小额剥皮”的 Peeling Chain 与“均等切片”的 Layering Split）。

### C. 知识库模式层（Motif Knowledge Representation）

- **丰富典型模式的流向原型（Flow Archetypes）**：
  - 在拓扑模式（Motif）定义中引入模式级流向先验模板；
  - 为典型洗钱模式预置经验流向权重（例如：剥皮链预置主干与剥离支流的非对称比率，均等分流预置对称比率，汇聚归集预置多进一出汇流比率）。

## 3. 模块职责与改造实施指南（请自行定位项目中对应实现）

### 1. 数据契约与环境状态层

- 检索定义图节点、边、场景规格的核心数据模型文件；
- 扩展边模型与场景规格模型，赋予流向权重与规模等级属性；
- 确保导出图（Graph Export）的数据结构中，边属性与全局元数据中包含新增字段。

### 2. 硬约束校验层（Hard Verifier）

- 在操作合法性与图论校验器中，新增**分流物理守恒门禁（Flow Conservation Gate）**；
- **校验逻辑**：当某一节点发生分裂/分流（Split）动作产生多条出边时，计算所有出边流向权重的代数和，必须满足 $\sum \text{flow\_share} = 1.0$（允许工程微小浮点容差，如 $\pm 0.01$）；
- **反射支持**：若加和不守恒，校验器必须构造标准化、信息完备的错误提示文本，以便后续回传给 LLM 进行纠错反思。

### 3. 先验检索与上下文呈现层（RAG / Context Builder）

- 检索维护洗钱模式知识库及上下文压缩器的相关模块；
- 更新种子数据，补充各典型模式的流向比例先验；
- 在向规划 Agent 注入拓扑先验（JSON / 拓扑可视化）时，一并呈现该模式推荐的流向比例，使 Agent 具备选择参考。

### 4. 决策大脑与提示词层（Planner Agent & Prompts）

- 检索规划 Agent 的系统提示词（System Prompt）、动作格式规范与输出解析器；
- **提示词演进**：
  - 明确“流向守恒规则”：告知 Agent 在产生分支时必须指定各分支的流向比例，且加和必须为 1.0；
  - 引导 Agent 优先采纳 RAG 先验给出的模式原型流向比率，严禁凭空捏造无意义的复杂连续浮点数；
  - 引入宏观资金体量（Scale Tier）对拓扑复杂度（链长、分支度）的意图约束要求；
- **动作解析增强**：解析器在提取 Agent 输出动作时，正确提取分支比例；若 Agent 遗漏则回退至模式默认值或均分，保证边属性不为空。

### 5. 轨迹审计与语义导出层（Trajectory & Showcase）

- 检索负责记录执行轨迹及生成最终报告展示的模块；
- **实现结构派生式策略总结（Strategy Narrative）**：
  - 严禁让 LLM 无约束自由编造；
  - 依据图中实际发生并验证通过的模式序列（Pattern Sequence）、跨链跳跃路径以及终局目标角色，通过结构映射或模板化组合，生成一段紧扣图结构的战术总结陈述；
  - 将该策略陈述持久化至最终导出的图元数据中。

---

## 4. 交付与验收指标

1. **向后兼容与测试零回归**：项目中现有的所有单元测试与冒烟测试必须全数通过；
2. **守恒门禁拦截验证**：针对分流加和不为 1.0 的非法输入，硬约束校验器能够准确拦截并输出标准化反思信息；
3. **纯净度审计**：端到端运行生成后，导出的结果文件中除归一化的相对比例外，不得出现任何具体钱包地址、真实代币单位或微观时间戳。
