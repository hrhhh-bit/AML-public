### 两个初步生成文件的作用与学术定位

在 `output_distill` 目录下生成的两个文件，分别承担了**工程资产落地**与**学术论据支撑**的职能：

#### 1. `distilled_kb.json`（工程资产：提炼后的全量 Motif 先验知识库）

- **是什么**：这是系统的**物理知识底座**。它将原本非结构化的安全研报文本（如“攻击者将资金分批存入混币平台并小额转移...”），转化成了结构化、带语义拓扑规则的子图模式（Motif）全集。
- **作用**：它是下游 `aml_agent` 规划决策的直接检索源。每次 Agent 在拓扑状态机中推理下一步动作时，RAG 模块都会在这个文件中检索最匹配的洗钱拓扑基元（如 `peeling_chain`、`mixer_pooling`），提供给 LLM 作为少样本先验（Few-Shot Prior）。
- **学术意义**：证明了知识库的**“可执行性与可扩展性”**。

#### 2. `distillation_report.json`（学术论据：四大经验性检验审计报告）

- **是什么**：这是用于学术论文实验章节（Empirical Evaluation）和答辩的**自动化实验评测凭据**。
- **作用**：记录了从研报输入到知识入库的全流程量化指标，包括：切片成功率、Kahn 拓扑无环及分流守恒率（100%）、零噪声正则审计结果（0 残留）、同构去重记录、以及模式饱和度曲线。
- **学术意义**：证明了知识提取的**“客观性、严谨性与纯净度”**，向评审人证明这些先验子图不是研究者主观拍脑袋捏造的，也不是大模型胡乱生成的，而是有严格数学与逻辑验证的客观知识提炼。

### 报告提示“新增了 6 个 Motif”（12 + 6 = 18 的由来）

1. **初始基线（12 个 Seed Motif）**：
   在阶段 0 和阶段 1 中，为了验证图论算法（Kahn 拓扑排序）、分流守恒校验（$\sum flow\_share = 1.0$）以及 Agent 的状态机决策闭环，我们在系统底层内置了 **12 个经典的反洗钱种子 Motif**（例如基础的直连转账、简单跨链 Bridge、对称二分流等）。
2. **本轮研报提取（7 个提炼结果）**：
   当 `scripts/distill_handbook.py` 跑完慢雾手册后，大模型总共提取出 7 个 Motif。
3. **同构剪枝与入库去重（6 个新增，1 个剔除）**：
   知识库引擎在入库前执行了非同构去重（`flow_signature_set` 校验）：
   - 其中 1 个名为 `multi_hop_transfer_chain_v1` 的子图，被算法识别出与已有种子库中的多跳中继结构**完全同构**（边算子序列与出入度特征完全等价），系统触发安全策略 `isomorphic_skips` 将其**拦截过滤**；
   - 剩余 6 个具有全新拓扑特征（如非对称剥离链、多层扇出、混币池混淆等）被正式吸收。
4. **结果**：$12\text{（原始基线）} + 6\text{（研报新增）} = 18$。当前生成在 `output_distill/distilled_kb.json` 里的正是这 **18 个 Motif 的全量知识库**。

### `eval_cross_source.py` 脚本生成的产物是什么？

该脚本运行后只会产出 **一份独立的量化评测 JSON 凭据**：
`experiments/phase2_distillation_empirical/cross_source_consistency_nomad.json`。

它的内容大致如下：

```json
{
  "source_names": ["SlowMist", "CertiK"],
  "overall_consistency": 0.75,
  "pattern_overlap": {
    "Bridge_Exploit": 1.0,
    "DEX_Swap": 0.8,
    "Mixer_Obfuscation": 1.0,
    "Fanout_Split": 0.67
  }
}
```

它记录了针对同一真实事件（Nomad 事件），两家独立机构的研报在被本系统提炼后，其**边算子签名 Jaccard 相似度**（重合度与收敛程度）。

### 执行完这个脚本后，会对现有的知识库（`distilled_kb.json`）有所更新吗？

**答案是：绝对不会更新，也严禁更新！**

这是我们在科研系统架构设计中严格坚守的原则——**“评测流（Evaluation Pipeline）与入库流（Ingestion Pipeline）物理级解耦”**：

1. **为什么严禁更新？**
   - `distilled_kb.json` 是我们经过全量手册扫描、去重、验证后沉淀下的**标准生产基座资产**。
   - `eval_cross_source.py` 是一个**基准测试（Benchmark Test）**。如果每跑一次测试就擅自向 `distilled_kb.json` 追加数据，会导致：
     - 实验不可复现（多次运行测试会导致知识库体积不断漂移）；
     - 评测数据污染生产数据；
     - 无法保证控制变量。
2. **脚本内部的隔离实现**：
   在给你的 `eval_cross_source.py` 中，Distiller 提取出的 `motifs_slowmist` 和 `motifs_certik` 仅作为**内存中的临时图对象**传递给 `CrossSourceConsistencyEvaluator` 进行数学相似度比对。脚本**完全没有调用** `kb.merge_motifs()` 或任何对 `distilled_kb.json` 的写盘操作。

### 总结：当前体系中各项资产的定位全景

| 资产文件                                  | 属性分类                | 核心作用                                                                                           | 变动规则                                             |
| :---------------------------------------- | :---------------------- | :------------------------------------------------------------------------------------------------- | :--------------------------------------------------- |
| **`distilled_kb.json`**                   | **知识资产（Asset）**   | 包含 18 个经过同构去重的 Motif。是下游 Stage-1 LLM 规划与 RAG 检索的**唯一先验物理库**。           | 仅在有计划地进行多源知识库扩容批处理时才被追加更新。 |
| **`distillation_report.json`**            | **检验报告（Proof 1）** | 证明提取过程的**高合法率（100%）、零噪声（0 残留）、同构去重有效性**，以及模式边际递减趋势。       | 针对手册提取过程的全景审计，已固定归档。             |
| **`cross_source_consistency_nomad.json`** | **检验报告（Proof 2）** | 证明提炼算法具备**客观收敛性**，消除论文审稿人对于“大模型提取是否受分析师写作风格主观影响”的质疑。 | 作为 Check 2 的高置信度专项佐证，独立归档备查。      |

搞清楚这层解耦逻辑后，你可以放心执行 `eval_cross_source.py`。它只会为你的研究增加一份亮眼的客观性量化证书，绝不会破坏你刚才已经完美验证的 18-Motif 知识库底座。
