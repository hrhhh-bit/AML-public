### 一、 核心机制提炼（“它是如何运作的？”）

整个子系统由 **“物理隔离采集（`tools/crawler/`）”** 与 **“PRISMA 资格定标（`scripts/screen_manifest.py`）”** 两大独立流水线构成，严禁污染核心代码库 `src/` 与知识库。

```
[外部源: RSS / GitHub / 官网]
        │
        ▼ (HttpFetcher: RSS直提 / Tarball整仓 / 路径正则)
[负向拦截漏斗] ── 命中黑名单 ──> [丢弃，零网络开销]
        │ (通过: 长度 500~50000 / 时间窗 since 2021)
        ▼ (extractor + prune: 剪枝黑名单 + 编号重排)
[56 篇原始报告池 (data/raw_reports/)]
        │
        ▼ (screen_manifest.py: PRISMA 资格定标)
   ┌────┴────────────────────────┐
   ▼                             ▼
[Tier-1 正则状态机]           [Tier-2 LLM 语义终审]
(≥2跳资金流: Transfer/Swap/    (DeepSeek-flash, temp=0.1,
 Bridge/Split/Merge/Mixer)      排除利用步骤/静态快照/综述)
   └────┬────────────────────────┘
        ▼ 双层融合初筛 (Logical OR 救回)
  [17 篇初筛候选]
        │
        ▼ 人工代码级复核 (排除 Gyroscope / Resolv / Nostra 3 篇因果假阳性)
  [14 篇黄金定标集 (has_fund_flow=1)] + [42 篇负向对照 (has_fund_flow=0)]
```

#### 1. 采集与防反爬策略（数据从哪来、怎么抓）

- **多源差异化绕障**：
  - **Medium 博客（SlowMist/BlockSec/PeckShield/CertiK）**：利用 RSS `<content:encoded>` **原地提取正文**，完全绕过 Cloudflare 403 强反爬，避免二次 HTTP 访问；
  - **DeFiHackLabs & CryptoVulhub**：利用 GitHub Trees API 与 `codeload` **tarball 整仓下载**，本地解包提取，解决单文件 API 限流问题；
  - **CertiK 官网**：限定 `required_path_fragments`（如 `/incident-analysis/`），杜绝抓取裸域名下的商业/审计废纸。
- **配额机制澄清**：
  - 代码实际配额是“全局目标 80 / 单厂商保底 15 / 软上限 20”；
  - 最终的 **56 篇分布（SlowMist 7 / BlockSec 15 / PeckShield 20 / CertiK 14）是自然采集耗尽与黑名单硬淘汰（prune）后的实测存量**，非写死常量。

#### 2. PRISMA 资格定标机制（56 篇如何筛出 14 篇）

- **门禁硬指标（I1）**：必须存在**获利后（Post-Exploit）链上显式资金洗钱轨迹 $\ge 2$ 跳**。
- **Tier-1 正则**：识别转移动词、资产兑换（SWAP 需共现）、跨链桥（BRIDGE）、分流（SPLIT）、归集（MERGE）与混币器（Tornado/Railgun），换算跳数；
- **Tier-2 LLM 终审**：严格限定只看获利后洗钱，排除漏洞执行步骤（如 Flashloan 攻击步骤）；
- **人工复核固化（17 $\to$ 14）**：在台账 `eligibility_audit.json` 中以 `"method": "llm_verified_exclusion"` 固化记录排除 3 篇因果假阳性的证据链（Resolv 仅静态快照、Gyroscope 仅 1 wei 调用、Nostra 为 MEV 贿赂）。

### 二、 如何复现这个结果？（操作指南）

下游 Agent 给出了明确的**复现边界**：因为外部网页会更新、LLM API 未设固定随机种子，**学术界严谨的复现不应是在外网重新爬取，而是验证本地既有数据的一致性与管线确定性**。

#### 1. 离线一致性断言（推荐的学术验收方式，耗时 < 5 秒）

在 PowerShell 终端运行以下命令，验证 56 行台账、14 篇黄金集、3 篇假阳性剔除及 310 项单测是否绝对匹配：

```powershell
# 1. 运行核心断言脚本（校验 56 篇正文、14 篇定标、3 篇排除、零空值）
.\.venv\Scripts\python.exe -c "import csv, json, pathlib; p = pathlib.Path('data/raw_reports'); rows = list(csv.DictReader((p/'manifest.csv').open(encoding='utf-8', newline=''))); audit = json.loads((p/'eligibility_audit.json').read_text(encoding='utf-8')); gold = [r for r in rows if r['has_fund_flow'] == '1']; excl = [k for k, v in audit.items() if v.get('method') == 'llm_verified_exclusion']; missing = [r for r in rows if not (p / r['filename']).exists()]; empty = [r for r in rows if r['has_fund_flow'] not in ('0', '1')]; print(f'rows={len(rows)} gold={len(gold)} neg={len(rows)-len(gold)} excluded={len(excl)} missing={len(missing)} empty={len(empty)}'); assert len(rows) == 56 and len(gold) == 14 and len(audit) == 56 and not missing and not empty and len(excl) == 3; print('>>> ALL CHECKS PASSED: 56 rows / 14 gold / 3 verified exclusions <<<')"

# 2. 运行采集与定标专用测试（离线）
.\.venv\Scripts\python.exe -m pytest tests/test_crawler.py tests/test_screen_manifest.py -v

# 3. 运行全量测试套件
```
